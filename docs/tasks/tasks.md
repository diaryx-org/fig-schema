# Tasks

Deferred work on `fig-schema`, one file per commitment. A task states a done
state; a fix that takes ten minutes gets a commit instead.

Closing is an edit rather than a delete — `status: done` and the commit or
release that resolved it — so what is finished stays findable by grep and
leaves the `contents` above.

What does not belong here: behaviour that shipped, which is documented in the
crate's rustdoc and README; and a commitment to consumers, which is a changelog
entry. A document that *argues* for a change and might lose the argument would
be a proposal, and this repo has no `docs/proposals/` yet.
